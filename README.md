# Ab1BaS GameCheck

Диагностика проблем с играми на Windows: вылеты, зависания, синие экраны и ошибки античитов (FACEIT, Riot Vanguard, Easy Anti-Cheat, BattlEye).

| Скрипт | Для чего |
|---|---|
| [Ab1BaS-CrashCheck.ps1](Ab1BaS-CrashCheck.ps1) | Игра вылетает, зависает, ловишь синий экран |
| [Ab1BaS-AntiCheatCheck.ps1](Ab1BaS-AntiCheatCheck.ps1) | Античит не запускается или выдает ошибку (VAN, TPM, Secure Boot, HVCI и т.д.) |

Диагностика сети (пинг, потери пакетов) лежит отдельно: [Ab1BaS-NetCheck](https://github.com/ab1bas0/Ab1BaS-NetCheck).

## Права администратора не нужны

Скрипты запускаются от обычного пользователя и **не просят прав администратора**. Без этих прав скрипт физически не может ничего сломать в системе: удалить системные файлы, поменять драйверы, BIOS или настройки защиты. То, что Windows без администратора не показывает, скрипт честно пишет как недоступное.

## Скрипты только читают

**Что они делают:**
- читают журналы Windows за последние 14 дней: какая программа упала, на каком модуле и с каким кодом, были ли синие экраны, сбросы видеодрайвера, аппаратные ошибки;
- смотрят видеокарту и драйвер, память, файл подкачки, свободное место, библиотеки Visual C++ и .NET;
- для античитов: версию Windows, UEFI, Secure Boot, TPM 2.0, изоляцию ядра (VBS/HVCI), службы античитов, программы, которые с ними конфликтуют, и драйверы, которые заблокировала Windows.

**Чего они не делают:**
- ничего не скачивают и не устанавливают, в коде нет ни одной загрузки из интернета;
- ничего не меняют: ни Windows, ни BIOS, ни реестр, ни игры, ни античиты;
- нет закодированных или спрятанных команд, весь код обычным текстом;
- никуда не отправляют данные: отчет сохраняется на рабочий стол и копируется в буфер обмена, а показывать его кому-то или нет, решаешь ты;
- не собирают пароли, имя компьютера, имя пользователя, MAC-адреса и IP. Пути вида `C:\Users\Имя` в отчете заменяются на `<user>`.

## Как проверить самому

1. Открой нужный скрипт и посмотри код.
2. Скопируй код в ChatGPT, Claude или любой другой ИИ и спроси: безопасен ли он, что он меняет в системе и нужны ли ему права администратора.
3. Загрузи файл на [virustotal.com](https://www.virustotal.com/).

## Как запустить

1. Открой нужный скрипт и нажми кнопку **Download raw file** справа сверху.
2. Нажми на скачанный файл правой кнопкой и выбери **Выполнить с помощью PowerShell** (в Windows 11 сначала нажми **Показать дополнительные параметры**).

   Или открой PowerShell и вставь (имя файла поменяй на свой):
   ```
   powershell -ExecutionPolicy Bypass -File "$HOME\Downloads\Ab1BaS-CrashCheck.ps1"
   ```
   `Bypass` разрешает запуск только этого одного файла в этом одном окне и ничего не меняет в системе.
3. Отчет уже в буфере обмена: вставь его (Ctrl+V) в чат с продавцом. Копия лежит на рабочем столе.
